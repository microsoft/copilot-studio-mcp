# Support

## How to get help

This MCP server is a bridge to Microsoft Copilot Studio; using it requires a
Copilot Studio license and environment at minimum. Support for issues
encountered while using this server follows Copilot Studio's existing support
policy:

[Find community help and support - Microsoft Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/fundamentals-support)

That page covers community forums, feedback channels, and how to get support
directly from Microsoft.

## Microsoft Support Policy

Support for this project follows the Microsoft Copilot Studio support policy
linked above.
